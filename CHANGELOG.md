# Changelog

## v0.1.0 - 2026-06-04

Initial public release.

### Added

- Bilingual English/Vietnamese AI solution architecture course.
- GitHub Pages landing page.
- Repository-grounded architecture deep dives for 17 AI repositories.
- Validation scripts for the course layer and deep-dive documentation.
- Community files and contribution workflow.
- Architecture templates for ADRs, runtime selection, RAG data contracts, LLMOps scoring, production readiness, and security review.
- Capstone project for an Enterprise Knowledge Copilot.
- Architecture assessment pack with English and Vietnamese tracks.

### Notes

- The upstream source checkouts used during analysis are intentionally excluded from the published repository.

### Release Intent

This release establishes the repository as a complete AI solution architecture knowledge system rather than a collection of notes. The structure is designed for three audiences: senior engineers who need practical production patterns, solution architects who need defensible decision artifacts, and Vietnamese engineering teams who need high-quality bilingual material with accurate technical language.

The release also adds the assets needed for community growth: a polished README, a live GitHub Pages entry point, reusable templates, a capstone scenario, an assessment pack, a share kit, and validation automation. Future releases can now improve specific domains without changing the overall knowledge architecture.

### Validation

The documentation is expected to pass two validation scripts before release. The course validation checks that the bilingual learning system, templates, capstone, assessment pack, and visual assets exist and are substantive. The repository deep-dive validation checks that all expected English and Vietnamese architecture documents exist, include Mermaid diagrams, and avoid unfinished draft markers. This keeps the public repository from drifting into shallow or incomplete material.
