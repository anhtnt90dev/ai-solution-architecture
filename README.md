# AI Solution Architecture Knowledge System

This repository contains a bilingual English/Vietnamese knowledge system for modern AI solution architecture.

Start here:

- [Learn AI Solution Architecture](./learn-ai-solution-architecture/README.md): course-style guide synthesized from the architecture deep dives.
- [Repository Architecture Docs](./repo-architecture-docs/README.md): detailed bilingual architecture notes for 17 AI repositories.

## What Is Covered

- AI app and agent architecture.
- Model serving and inference.
- Fine-tuning and distributed training.
- RAG and vector databases.
- Observability, evaluation, and LLMOps.
- Tooling, MCP, and AI platform design.

## Validation

Run from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File learn-ai-solution-architecture\validate-knowledge-system.ps1
powershell -ExecutionPolicy Bypass -File repo-architecture-docs\validate-docs.ps1
```
